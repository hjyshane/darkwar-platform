### 3.1 새 `handover.md`의 뼈대 (≤120줄)

1. **한 문단**: 이 프로젝트가 지금 어디까지 왔나 (운영 중인 것 / 코드만 있는 것)
2. **막힌 것**: 사람 손이 필요한 것 + 이유 (예: 클라우드 VM 설치 스크립트 미실행, 맥 `git pull` 등)
3. **실데이터로 한 번도 안 돌린 것**: CLAUDE.md가 약속한 목록. 일지의 "미확인/아직 실행 전" 마커에서 뽑는다 (§5)
4. **머신 지도**: Windows 수집기 / Mac / GCE VM — 무엇이 어디서 돈다, 재시작 레시피 링크
5. **최근 2주 한 줄 요약 + 링크**: 각 줄은 `docs/log/…#앵커` 로 연결
6. **어디를 읽을지**: 런북/ADR/스펙 포인터 표

규칙: 일지가 아니라 **덮어쓰는 문서**다. 항목이 해결되면 지우고, 사연은 `docs/log/`에 남긴다.

## 4.5 개정 (2026-11-12) — `git log 11-08..11-12` 대조 결과

원안(§1~§4)에 아래 세 가지를 더한다.

1. **handover가 4일·약 40 PR 뒤처져 있다.** 마지막 수정 커밋은 `dcccb900`(11-08). 그 뒤 #577~#591이 들어갔다: 이벤트 가이드/계산기/연맹 페이지/플레이어 헤더 Phase B, 이민 이력(0317~0320), 지도 아틀라스, 클라우드 연맹 도움(#591). 새 handover를 쓰기 전에 이 구간을 **먼저** 읽어 `log/2026-11.md`에 항목으로 추가해야 한다 — 분할만 하면 낡은 상태가 그대로 옮겨진다.
2. **CLAUDE.md의 "이미 내린 결정"이 어긋났다.** CLAUDE.md는 "state-changing command는 영원히 금지"라고 쓰지만 **ADR-0003(11-11, accepted)이 이를 개정**해 수집 계정이 허용 목록의 게임 내 동작(연맹 도움·기술 기부·선물 수령)을 할 수 있다고 했다. 에이전트가 CLAUDE.md를 먼저 읽으므로 가장 위험한 낡은 줄이다. → **수정 완료(2026-11-12, 사용자 승인):** CLAUDE.md의 ADR-0002 불릿만 ADR-0003 내용으로 갱신했다. 커밋은 아직 안 했다.
3. **새 handover에 꼭 들어갈 "진행 중" 항목**: ① `cloud-actions.md`는 "아직 루틴 코드로 만들지 않았다"고 쓰는데 #591이 화면 구동 코드를 넣었다 — 어느 쪽이 맞는지 확인, ② `39980601` "handshake spike: login is signed, active path is no-go" — ADR-0002의 "송신 코드 없음"과 연결되는 결론이라 handover와 ADR 양쪽에 반영 필요, ③ 11-08에 "VM에서 한 번도 실행 안 했다"던 설치 스크립트가 #591 시점엔 실행됐을 가능성(에뮬 320x640 수동 검증 기록이 11-11).

그에 따라 §3.1 뼈대에 **"문서가 서로 어긋난 곳"** 한 칸을 추가한다(위 2번 같은 항목을 해결될 때까지 적는다).
